GET

	Get all posts

	GET https://jsonplaceholder.typicode.com/posts

	Get one post

	GET https://jsonplaceholder.typicode.com/posts/1


With query parameters

	GET https://jsonplaceholder.typicode.com/posts?userId=1


2. POST

	POST https://jsonplaceholder.typicode.com/posts

Headers:

	Content-Type: application/json

Body:

	{
  	  "title": "My Test Post",
  	  "body": "Testing POST from my API client",
   	  "userId": 1
	}


3. PUT

	PUT https://jsonplaceholder.typicode.com/posts/1

Headers:

Content-Type: application/json

Body:

{
  "id": 1,
  "title": "Updated Post",
  "body": "Testing PUT operation",
  "userId": 1
}
4. PATCH
PATCH https://jsonplaceholder.typicode.com/posts/1

Headers:

Content-Type: application/json

Body:

{
  "title": "Partially Updated Title"
}

PATCH is useful for testing your client's ability to update only selected fields.
5. DELETE
DELETE https://jsonplaceholder.typicode.com/posts/1

Usually no body is needed.

6. HEAD

Good for testing response headers without downloading the response body:

HEAD https://jsonplaceholder.typicode.com/posts/1
7. OPTIONS
OPTIONS https://jsonplaceholder.typicode.com/posts/1

This is useful for testing how your client handles HTTP method capabilities and headers.
