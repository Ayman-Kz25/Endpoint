Project Set-up:

Create the Vite project

npm create vite@latest . -- --template vanilla

Install Tailwind CSS

   npm install tailwindcss @tailwindcss/vite

3. Install Lucide

   npm install lucide

4. Install Notyf (For toast notifications)

   npm install notyf

5. Install CodeMirror 6 (For JSON request-body editor)
   
   npm install @codemirror/state @codemirror/view @codemirror/lang-json @codemirror/commands @codemirror/language @codemirror/theme-one-dark

6. Install Prism (For syntax highlighting)

   npm install prismjs
